## 🚀 What I'm Building

### 👁️ NETRA — Network Threat Recognition & Analysis

A multi-stage **Network Intrusion Detection System** built around an **R → Python → Julia** pipeline.

- 📊 **R** — statistical analysis, feature selection & exploratory analysis
- 🤖 **Python** — preprocessing, XGBoost, Optuna & SHAP
- 🚀 **FastAPI + Docker** — model serving & deployment
- ⚡ **Julia** — Random Forest performance benchmarking
- 🧪 **NSL-KDD** — 41 network features → 5 traffic classes
- 📈 **97.30% Binary ROC-AUC** on the official `KDDTest+`
- 🔍 Dedicated **failure & distribution-shift analysis**
- 🧠 SHAP-based model explainability
- 🚀 Docker API latency: **15.03 ms mean / 16.56 ms P95**
- ⚙️ Julia benchmark: **99.873% accuracy / 0.9276 macro-F1**

> One of the biggest lessons from NETRA: high cross-validation performance does not automatically mean good generalization.

🔗 [View NETRA](https://github.com/chaRITSzard/NETRA)
